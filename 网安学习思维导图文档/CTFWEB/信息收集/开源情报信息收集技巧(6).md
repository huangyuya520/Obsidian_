## 补：Bing 搜索语法

### `LinkFromDomain`运算符
Bing 的 `LinkFromDomain` 是必应（Bing）搜索引擎的一个特色高级搜索运算符，==用于查找包含**从指定域名引出的外部链接**的网页==

- 语法：
```
LinkFromDomain:域名（冒号前后不能有空格，且不需要加引号）
```

==基本介绍==

- **作用**：找出所有在其页面内容中包含指向某个特定域名（URL）链接的网页。
- **语法格式**：`LinkFromDomain:域名`（冒号前后**不能有空格**，且不需要加引号）。
- **示例**：输入 `LinkFromDomain:inteltechniques.com` 可以搜索出所有在其页面上放置了指向 `inteltechniques.com` 链接的网页


==主要特点与用途==

- **独占属性**：这是必应相对独特的运算符之一，在常规 Google 搜索中通常没有完全对等的同名字段。
- **外链分析**：常用于网站管理员、SEO（搜索引擎优化）人员或安全研究员追踪某个网站的外部链接来源，查看谁在自己的网站或者目标网站上做了推荐或引用




### Contains运算符
Bing 搜索中的 `contains:` 运算符==用于查找包含特定文件类型链接的网页==

- 语法：
```
contains:文件后缀 关键词 或直接搜索 contains:文件后缀
```


==作用与功能==

- `contains:` 可以帮你找到在其页面中包含指向特定格式文件（如 `.wma`、`.pdf`、`.mp3` 等）链接的网站。
- 它常用于寻找提供特定可下载资源的网页


==使用注意事项==

- 冒号 `the colon` 后面**不能有空格**，必须紧跟文件类型。
- 该运算符主要针对网页中包含的**链接类型**，而不是网页本身的文件格式（页面本身是 HTML，但它包含某类文件的下载或引用链接）

 可以==通过 必应视觉搜索 使用图像而不是文本来搜索网络，快速查找相似图片、匹配商品并识别物体==

# OSINT常用工具

## 元数据提取工具-Exiftool
ExifTool 是一个==用来读取、写入和编辑文件元数据（Metadata，即描述文件属性的数据）的强大开源命令行工具==

==**(使用教程略，学过CTF杂项的同学对这个工具很熟悉，这里不多讲)**==


==核心功能==

- **读取元数据**：支持查看照片、音频、视频、PDF 等数千种文件格式的详细参数，如拍摄时间、相机型号、GPS 地理位置、色域配置等。
- **写入与修改**：可以添加、修改或删除元数据标签，比如批量修正照片的拍摄日期、添加版权信息。
- **提取预览图**：能深入文件内部，从 RAW 格式等专业影像文件中提取嵌入的高清预览图或缩略图。
- **跨平台支持**：支持 Windows、macOS 和 Linux 系统





## 文档下载工具-Metagoofi
**Metagoofil** 是一款==专门用于**信息收集（OSINT，开源情报截取）** 的经典网络安全工具==

它通过在搜索引擎（主要是 Google）中进行自动化搜索，查找并下载目标网站公开的特定格式文档，然后深度提取这些文档中隐藏的**元数据（Metadata）**


==核心功能与工作原理==

Metagoofil 的工作流程非常简单高效，主要分为以下三个步骤： [[1](https://github.com/kurobeats/metagoofil)]

- **自动搜索**：基于用户指定的域名（如 `target.com`），利用 Google 语法自动化搜索该域名下公开挂载的各种文档。

- **本地下载**：将搜索到的公开文档批量下载到本地指定的目录中。

- **元数据解析**：利用解析库（如 `Hachoir` 和 `PdfMiner`）提取这些文档中由于员工疏忽而未擦除的后台隐藏信息


==能够提取的敏感信息==

通过分析下载的文档，Metagoofil 可以帮助渗透测试人员或安全审计员获取以下极具价值的情报： [[1](https://medium.com/purple-team/collecting-metadata-with-metagoofi-ef7c52dbfa00), [2](https://www.geeksforgeeks.org/linux-unix/metagoofil-tool-to-extract-information-from-docs-images-in-kali-linux/)]

- 👤 **用户名/作者名**：创建或修改该文档的员工真实姓名或系统账号名。这些名字可直接用于后续的社会工程学攻击或暴力破解。

- 💻 **软件版本**：制作文档所使用的办公软件及版本（例如 Microsoft Office 2016、Adobe Acrobat 等），有助于黑客寻找特定网络组件的已知漏洞。

- 🖥️ **服务器与内部路径**：文档元数据中常常暴露本地文件系统的绝对路径、共享网络资源名称、服务器名称甚至是本地 IP 地址。

- 🗺️ **硬件与 MAC 地址**：部分旧版 Microsoft Office 文档可能还会残留硬件设备信息或网卡 MAC 地址



==支持的文件格式==

Metagoofil 主要支持以下常见的企业办公和网络文档格式： [[1](https://hackfun.org/2017/04/24/Kali-Linux%E4%BF%A1%E6%81%AF%E6%94%B6%E9%9B%86%E4%B9%8BMetagoofil/)]

- **PDF** (`.pdf`)

- **Microsoft Word** (`.doc`, `.docx`)

- **Microsoft Excel** (`.xls`, `.xlsx`)

- **Microsoft PowerPoint** (`.ppt`, `.pptx`)




==常用命令参数示例==

在终端中，Metagoofil 的标准使用语法如下： [[1](https://github.com/laramies/metagoofil/issues/13), [2](https://github.com/kurobeats/metagoofil)]


- ==**语法==：**
```
metagoofil -d <example.com> -t <doc,pdf> -l <200> -n <50> -o <myfiles> -f <results.html>
```

请谨慎使用此类代码。

- **`-d`**：指定要调查的目标域名。

- **`-t`**：指定要搜索的文件类型（用逗号隔开）。

- **`-l`**：限制在搜索引擎中搜索的结果总数（默认通常为 100 或 200）。

- **`-n`**：限制下载到本地的文件数量。

- **`-o`**：保存下载文档的本地文件夹目标路径。

- **`-f`**：最终分析报告的输出文件名（支持 HTML 格式，方便直观查看结果）
