# 补：搜索引擎分类简介
==在信息充斥的时代，研究人员所面临的挑战已不再仅仅是获取信息，而更在于了解搜索信息的途径与方法。对于从事开源情报（OSINT）研究的人员而言，可能需要超越谷歌搜索引擎的传统范畴进行思考。==

搜索算法和 cookie 不断改变搜索结果的展示方式，并根据搜索者进行个性化定制。在进行希望不受个人浏览历史、行为和指纹影响的搜索时，这一现象可能带来挑战。

因此，在寻求优质信息、验证调查结果及获取独特领域视角时，查看多个搜索引擎的结果显得至关重要。

在很多情况下，特定领域的深度搜索需借助专用搜索引擎来实现。这些专用引擎在某一特定搜索方式上表现卓越，但也暴露了它们在其他领域搜索能力的不足。了解搜索引擎之间的差异、优缺点及市场份额，有助于您选择合适的工具（或组合）以完成任务。

==作为一个普通的网络用户，在平时的学习工作中，仅仅接触到了表层网络，因为大多数的 Web 内容都是隐藏的，需要特殊的方法来访问。据不完全统计，表层网络（表网）中的信息仅仅包含整个互联网内容的4%左右，而其余部分都属于深网（deep web）和暗网（dark web/darknet）==

## 1. 网络层级划分

表层网络(表网)：==只占全部互联网的4%的内容==
深网(deep web)
暗网(dark web/darknet)


![](Pasted%20image%2020260922134151.png)


==表层网络（Surface Web）==：也称为 Visible Web、Indexed Web 或Lightnet，可通过正常方式访问；由标准网络浏览器可访问并通过传统搜索引擎索引的内容构成。它包含 YouTube、Facebook、Instagram、Twitter、Reddit 等热门网站。它可以通过标准搜索引擎进行搜索。


==深层网络（Deep Web）==：包含那些标准搜索引擎未索引，但仍在互联网上可访问的内容。这些内容可能需要特殊权限或身份验证才能访问，并可能因隐私或安全原因而受到保护。例如，某些需要登录才能检索的论坛。



==暗网（Dark Web）==：作为深层网络的一个子集，暗网是故意隐藏的部分，需要特定的软件和配置才能访问。它常被用于确保隐私和匿名性。尽管技术上暗网是深层网络的一部分，但在讨论中经常被单独提及。







## 2. 搜索引擎的类型
依据网络层次之别（表层与深层），搜索引擎可分为以下三类：通用搜索引擎、专用搜索引擎以及深层网络搜索引擎。

### 通用搜索引擎
表层网络，又称明网，涵盖了所有可通过标准网络浏览器和搜索引擎访问、索引的内容，对全体用户可见。
然而，值得注意的是，仅有约 4%的网站能被典型搜索引擎索引。


在搜索过程中，无论特定参数、查询方式或地域/活动/领域如何，搜索引擎均会依据特定的爬虫和索引提供服务。 检索结果受用户上网历史、地理位置、过往搜索、搜索词、软硬件配置等因素影响。 常见的搜索引擎示例包括 Google、Yandex、Bing、雅虎、百度、Qwant、Ask和
AOL。


#### Qwant搜索引擎
Qwant 是一款致力于将多元搜索引擎的检索成果整合于单一界面的搜索引擎。



#### AOL搜索引擎
美国在线（American Online），自 2000 年至 2009 年作为美国时代华纳的子公司，是一家知名互联网服务提供商。



### 专业搜索引擎
==专业搜索引擎致力于特定领域或特定类型的数据库，通常为广大公开可用资料以及部分需要专门访问权限的更为专业内容提供通道。尽管它们主要在表面网络环境下运行，但偶尔也能解锁某些不显眼且可视为深层网络一部分的数据库。在寻找特定领域的目标信息方面，这些搜索引擎具有很高的实用价值。==此类搜索引擎适用于从特定内容（如科学、艺术等）或特定环境（图书馆、音频/视频共享群组、在线社交媒体）中获取检索结果。部分知名实例包括GoogleScholar、Microsoft Academy、WolframAlpha、Smithsonian Research Online、Artcyclopedia 以及 WorldWideScience。

### 深网搜索引擎
==深层网络上的站点致力于搜索深层网络中尚未被通用搜索引擎索引，但可通过正确的权限或访问方式加以访问的部分。==

这类站点可用于检索私人数据库、受密码保护的网络及其他非公开领域。尽管政府机密数据和敏感的健康记录深藏于深层网络之中，但我们日常浏览的许多网站亦属深层网络范畴，例如电子邮件账户和个人银行门户。

通用搜索引擎难以从非索引互联网获取结果的场合（包括但不限于拒绝索引、需身份验证、动态内容、受限网络的网站），可以使用以下工具：Torch、DuckDuckGo、Ahmia、Candle、OnionLand 等



#### DuckDuckgo引擎
这款搜索引擎的用户界面设计简洁，同时提供两种独具特色的服务。它之所以受到广大用户的青睐，主要在于其独特的隐私保护机制。

==与Google 等其他搜索引擎不同，它不会记录或保存用户的搜索历史记录和访问过的网站，这一特点对于那些重视隐私保护以及进行敏感调查的用户来说至关重要。==此外，该搜索引擎还巧妙地整合了维基百科和 Wolfram Alpha 等众包网站的信息，以丰富传统搜索结果，提高搜索的相关性。尽管在搜索结果数量上可能不及其他热门搜索引擎，但其在准确性方面却表现得更加出色




#### Ahmia搜索引擎
Ahmia 是一款致力于在 Tor 网络中搜索隐藏服务的工具。值得关注的是，Ahmia 对于遏制滥用内容有着严格的限制。

## 3. 元数据搜索引擎
==元搜索引擎(meta search engine）是一种调用其他独立搜索引擎的引擎。“元”(meta）为“总的”“超越”之意，元搜索引擎就是对多个独立搜索引擎的整合、调用、控制和优化利用。==

这类引擎的核心价值在于**不对目标发起直接网络交互**，而是通过查询第三方持续测绘、索引和归档的海量被动数据，提取出隐藏在通信报文、服务配置、多媒体文件和软件构件中的上下文信息，以此勾勒出目标的数字全貌与关联网络。





==块数据搜索引擎的特点：== 
第一，涵盖较多的搜索资源，可随意选择和调用源搜索引擎；
第二，具备尽可能多的可选择功能，如资源类型(网站、网页、新闻、软件、FTP、MP3、图像等）选择、返回结果数量控制、结果时段选择、过滤功能选择等；
第三，强大的检索请求处理功能(如支持逻辑匹配检索、短语检索、自然语言检索等）和不同搜索引擎间检索语法规则、字符的转换功能(如对不支持“NEAR”算符的搜索引擎，可自动实现由“NEAR”向“AND”算符的转换等）；
第四，详尽全面的检索结果信息描述(如网页名称、URL、文摘、源搜索引擎、结果与用户检索需求的相关度等）； 第五，支持多种语言检索。

## 5. FTP 检索引擎
FTP 服务器是具有公共 IP 地址的计算机，用于存储文件。虽然可以使用强制访问凭据来保护这些内容，但这种情况很少发生。大多数都是公开的，可以从网络浏览器中访问。与十年前相比，使用FTP 传输文件的总体情况很少，但服务器仍然大量存在。Google 和 Bing 对FTP 服务器上最公开的数据建立索引。 需要自定义搜索字符串才能过滤不需要的信息。如果需要查找标题中包含“confidential”一词的任何文件，可以在 Google 和Bing 上进行以下搜索。


payload：`inurl:ftp -inurl:https "confidential"`


这种类型的手动导航通常会显示传统搜索所保留的大量公开可用的文档。根据这种导航可以找到由公司、政府机构和军队托管的极其敏感的文件。大多数文件传输协议 (FTP) 服务器已被 Google 索引，但还有其他第三方选项值得探索。



#### Mamoht FTP搜索引擎
此俄罗斯 FTP 服务器允许您按托管内容的国家/地区隔离搜索结果。这可能是由 IP 地址决定的。
