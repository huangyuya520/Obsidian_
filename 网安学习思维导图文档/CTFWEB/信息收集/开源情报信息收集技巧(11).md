## Wayback Machine官网
Wayback Machine（网站时光机）==是美国非营利组织互联网档案馆==（Internet Archive）推出的数字档案馆，被广泛应用于开源情报搜集（OSINT）、网络安全调查和数字取证。

互联网档案馆在搜索已删除网络内容方面所展现出的卓越功能。通过访问 Wayback Machine 网站，用户或许能够浏览到目标域名的相关信息，然而，自动采集数据的方式则更具优势，能够更加高效、全面地获取所需内容。

==工具核心功能==

- **历史快照追溯**：定期捕获并保存全球数以亿计网页在不同时间点的历史版本，即使原始网页已被删除、修改或网站彻底关闭，也能完整查阅其旧貌。

- **主动归档（Save Page Now）**：用户可以手动输入目标URL，立即强制对当前网页进行实时抓取存档，锁定关键证据。

- **多维度检索**：支持按网址（URL）、时间线日历以及关键词快速定位特定历史时期的页面数据



==在高级情报搜集（OSINT）中的应用场景==

- **资产与漏洞追踪**：挖掘目标企业早期暴露但现已移除的敏感目录、员工名录、内部API接口或测试页面。

- **背景与舆情调查**：回溯公众人物、竞争对手或恶意组织在过去发表但已被删除的言论、文章、声明或公告。

- **数字法律取证**：为侵权、合同变更、虚假宣传或网络攻击提供不可篡改的历史网页快照证据。


URL： http://web.archive.org/




## 网站变化监测
你可能有一个敏感的 URL，不想与在线服务共享，或者一个有非常微小变化的网站，免费服务无法检测到这些变化。这就是 Change Detection 的用武之地。它是本地安装的，仅供你使用。

项目地址： https://github.com/dgtlmoon/changedetection.io





## Archive Box
==**ArchiveBox 是一款开源、自托管的个人互联网归档系统**==。它可以将你想要收藏的网页、播客、视频以及电子书完整地克隆到本地，防止因为网页被删、网站关闭或付费墙阻挡而导致的信息丢失。

无论是作为网络安全领域的**高级情报搜集（OSINT）** 工具，还是作为个人的知识库管理工具，ArchiveBox 都能提供极其强大的数据留存能力。
==与上述Change Detection项目功能相似，监控目标网站变化==


📥 核心归档格式

与其他简单的“书签”工具不同，ArchiveBox 不仅仅是保存一个链接，它会同时提取并生成以下多种格式的文件：

- **标准网页：** 包含完整的 HTML、图片以及提取出来的纯文本。

- **离线快照：** 单个文件的 HTML（DOM）快照（使用 SingleFile）。

- **媒体文件：** 提取网页中的视频（通过 yt-dlp）和音频。

- **视觉备份：** 网页的完整截屏（PNG）以及 PDF 电子书格式。

- **元数据：** 标准的 WARC（网络归档格式）、Favicon 图标以及标题元数据。



🛠️ 核心功能特点

|功能维度|特点说明|
|---|---|
|**多源输入**|支持从浏览器书签（Chrome/Firefox）、Pocket、Instapaper、RSS 订阅源、甚至 TXT 文本中批量导入链接。|
|**自动化运行**|拥有强大的命令行工具（CLI）和定时任务（Cron），可以设置为每天自动抓取特定网站的情报更新。|
|**现代化 UI**|自带一个基于 Django 开发的 Web 管理后台，支持全文检索、标签分类和状态监控。|
|**数据零锁定**|所有抓取的数据都以标准的、易读的文件结构（HTML/PDF/MP4）存储在本地硬盘中，即使停用 ArchiveBox，数据依然可用。|
|**隐私保护**|运行在私有服务器上，不会向第三方泄露你的浏览偏好或敏感的情报搜集目标。|


🔍 在情报搜集（OSINT）中的应用场景

- **证据固定与去中心化：** 在面对敏感事件、突发新闻或漏洞情报时，网页随时可能被删除或修改。使用 ArchiveBox 可以秒级生成不可篡改的本地证据链。

- **离线威胁分析：** 抓取恶意软件分析报告、黑客论坛帖子或钓鱼网站页面后，分析人员可以在沙箱环境中安全地查看离线快照，无需直接连接到潜在危险的域名。

- **数字足迹追踪：** 批量监控特定目标人物或组织在社交媒体、博客上的更新，自动下载其发布的媒体文件。


项目地址： https://github.com/ArchiveBox/ArchiveBox








## Spiderfoot
SpiderFoot==是一款强大的开源情报（OSINT）自动化侦察与足迹分析工具==

核心功能与特点

- **自动化数据源整合**：自动查询100多个公共数据源（如Shodan、HaveIBeenPwned、DNS等），收集IP地址、域名、电子邮件、电话号码及用户名等目标情报。

- **攻击面映射**：帮助安全分析师和渗透测试人员快速发现目标资产、漏洞、泄露的凭据及威胁情报。

- **双模式支持**：同时提供直观的Web图形用户界面（GUI）和高效的命令行模式，方便不同场景下使用。

- **模块化架构**：支持高度自定义扫描模块，用户可按需启动特定查询任务。




## Maltego
**Maltego** 是一款==用于开源情报（OSINT）收集和图形化链接分析的强大平台==。

它可以把互联网上分散的数据自动挖掘出来，并用直观的关系图展现给用户。



==核心功能与特点==

- **数据可视化**：通过节点和连线展示目标之间的内在联系，将复杂的网络关系变成清晰的图表。 [[1](https://blog.csdn.net/2302_82189125/article/details/135910618), [2](https://cloud.tencent.com/developer/news/1564451)]

- **Transform（变换机制）**：内置或通过 API 运行自动化查询，通过一个实体（如域名）自动衍生出其他相关实体（如 IP 地址、邮箱、公司、社交账号等）。 [[1](https://zhuanlan.zhihu.com/p/542249048), [2](https://blog.csdn.net/hao_wujing/article/details/149183244)]

- **多平台支持**：基于 Java 开发，可在 Windows、macOS 和 Linux（如 Kali Linux）上流畅运行。 [[1](https://sysin.org/blog/maltego-4/), [2](https://zhuanlan.zhihu.com/p/542249048)]

- **丰富组件**：
    - **Maltego Graph**：用于深入调查复杂的开源情报和网络威胁。
    - **Maltego Search / Monitor**：快速运行初步搜索并实时监控威胁。




==常见应用场景==

- **网络安全与渗透测试**：在渗透测试前期收集目标域名的子域名、服务器 IP、旁站以及管理员邮箱等信息。

- **威胁情报与执法调查**：追踪恶意黑客组织、网络诈骗或数字取证，把零散的网络痕迹串联成完整的证据链。
