
# 常见命令执行的过滤与bypass绕过的手法

## ==补：linux命令组成部分==
- Linux命令的通用格式如下
空格作为不同成分的分隔符号
- 命令字符 `[选项]` `[参数]`

- 选项及其参数
    - 选项：用于调节命令的具体功能
		`-` 引导，一般单个字符，如`-l`
		`--` 引导，一般多个字符，例如`--all`
- 参数：命令操作的对象，比如文件、目录等
示例：`ls -all/tmp`

## 补：Linux中的shell变量
- shell变量
	- Linux的Shell编程中，变量和其他语言一样是用于存储特定的数据值的名称
- 定义与使用
	- ==定义变量直接使用 `<变量名> = <变量值> 的格式即可，如LIBPATH="/tmp/lib.so"
	- 使用变量则需要在变量名前加上\$符号，如echo \$LIB PATH
- Linux中默认自带的一些变量
```
$[PS2】为符号>，$[PS4]为符号+，$[IFS]为内部字段分隔符，$[9]为空字符串等
```


## 补：==Linux中常见的分隔符==
- Linux中具备多种分隔符
	- 分号（`;`）：多条命令的分隔符，命令会连续执行下去
	- 与（`&&`）：多条命令的分隔符，连续执行直至命令失败终止
	- 或（`||`）：多条命令的分隔符，连续执行直至命令成功终止
	- 单个与（`&`）：效果同分号
	- 管道符号（`|`）：前一条命令的执行结果输出给后一条命令
- 其他特殊符号
	- 重定向符号`>` `<`


## 补：==Linux命令中的通配符==
- 什么是通配符
	- 是一种用于匹配文件名或字符串的特殊字符或模式
	- 允许你根据一定的模式来匹配文件名或字符串，而不需要提供完整的准确名称
- Linux中常用通配符
	- 问号（`？`）：问号通配符匹配单个任意字符。如`f?ag`，可以是`faag`也可以是`flag`
	- 星号（`*`）：匹配零个或多个任意字符。如*.txt，匹配所有txt结尾的字符
	- 方括号（`[]`）：匹配指定范围内的单个字符或字符集合中的任意一个字符
		如`flag[12].txt`匹配`flag1.txt`和`flag2,php`
	- 花括号（`{}`）：表示可选的字符串。如`flag{12，13}`，表示flag12和flag13





## ==常见的命令执行的限制方式==

### ==方式一：限制分隔符号==

- 不允许使用空格、分号

### ==方式二：限制具体使用的命令/关键字==

- 不允许使用cat等命令
- 不允许访问名为admin.config文件等



## Bypass——命令执行空格过滤

- ==方法一：利用Linux中自带的变量==
	- 使用`$IFS(1)`:`cat${IFs}flag.php`
	或
	- 使用`$IFS(2)`：`cat$IFS$9flag.php`
- ==方法二：使用别的分隔字符==
	- 使用Tab符号：`cat%09flag.php`

- ==方法三：使用重定向符号==
	- 例1：`cat < flag.php`
	- 例2：`cat <> flag.php`

## Bypass——命令执行关键字过滤
- ==方法一：使用替代命令==
	- 比如过滤了文件读取命令cat，那么是否有其他文件读取命令？
		- `nl, more, less, tac, tail,od, sort等`
- ==方法二：引号“拼接”字符串==
	- 如`l''s`等价于Is
- ==方法三：反斜杠==
	- 如`ca\t flag`等价于`cat flag`
- ==方法四：通配符==
	- 假设过滤了关键字`flag`
	- 可以使用的`cat fla*`等价于`cat flag`
	- 甚至还能有这样的 paylaod:`/bin/ta? f???等价于/bin/tac flag`
- ==方法五：编码绕过==
	- base64编码：`echo <base64编码的命令> | base64-d | bash`
	- hex编码：`echo <hex编码>|xxd -r -p|bash`
	- 另一种hex编码：`$(printf "<\x开头的hex编码>”)`

# 补：PHP——escapshellarg函数介绍

`escapeshellarg` 函数==用于给字符串两端加上单引号，并转义内部的单引号，确保字符串在传给系统命令行时只被当成**单个安全参数**处理，防止命令注入==

- 语法：
```
$<safe_arg> = escapeshellarg(<$username>);
```

核心作用

- ==**加单引号**：把输入内容用单引号包起来。==
- ==**转义单引号**：把内容里自带的单引号做安全处理。==
- ==**防止注入**：阻止用户输入空格或特殊符号来拼接执行其他命令==

注意事项

- ==它确保的是单个参数的安全。如果和双引号一起错误拼凑，有时在特定环境下仍需小心逻辑漏洞。==
- ==它和 `escapeshellcmd` 不同：`escapeshellarg` 管参数本身，`escapeshellcmd` 管整个命令的符号==


# 补：PHP——escapshellcmd函数介绍
**`escapeshellcmd`** 函数==用来转义字符串中可能用来欺骗 shell 执行恶意命令的特殊字符==。它确保用户输入在传给 `exec()`、`system()` 或反引号等执行操作符之前是安全的，并返回处理后的字符串

- 语法：
```
escapeshellcmd(<$command>)
```

主要作用

- ==防止用户通过输入分号、管道符等注入并执行**多个不同的命令**。==
- ==对危险字符（如 `&`, `;`, `|`, `*`, `?`, `~`, `<`, `>`, `(`, `)`, `$`, 等）添加反斜线转义。==
- ==引号（`'` 和 `"`）仅在不配对时才会被转义==

与 `escapeshellarg` 的区别
- **`escapeshellcmd`**：转义整个**命令字符串**，防止执行新命令，但用户仍可自由传入任意数量的参数。
- **`escapeshellarg`**：转义单个**命令参数**，给参数加单引号并转义内部单引号，确保只传一个确定参数。两者混用不当有时会产生参数注入漏洞


# escapshellarg函数与escapshellcmd函数混用时bypass技巧
==本质这两个函数，单个使用都能够规避安全问题，但是混合使用反而会引入安全问题==
在 PHP 开发中，同时使用 `escapeshellarg()` 和 `escapeshellcmd()` 对参数进行过滤是一种典型的**错误防御组合**。两者混用会导致**引号被破坏并发生逃逸**，进而引发**参数注入（Argument Injection）甚至** **任意命令执行（RCE）** 

==两个函数的处理逻辑存在天然冲突==：

- **`escapeshellarg($str)`**：在字符串两端包裹单引号 `'`，并将原字符串中的每个单引号 `'` 替换为 `'\''`。
- **`escapeshellcmd($str)`**：会转义命令中的特殊字符，包括将单个反斜杠 `\` 转义为 `\\`。
