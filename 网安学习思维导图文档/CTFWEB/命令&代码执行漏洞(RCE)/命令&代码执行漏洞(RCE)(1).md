# 常见命令注入函数/方法介绍

## system函数介绍
`system()` 函数==用来执行外部的操作系统命令，并且会直接把命令执行后的结果输出到网页或屏幕上==，它还会返回命令执行的最后一行输出。

- 语法：
```
system ( <$系统命令>,<结果码> )
					(可选参数)
```


## exec函数介绍
`exec()` 函数==用来运行外部程序或系统命令==。它在服务器上执行命令行指令，并返回命令输出的最后一行。

- 语法：
```
exec(<$系统命令>, array &$<output>, <结果码>)
						(可选参数)  (可选参数)
```

**`output`**：可选参数。如果传入一个数组，命令的每一行输出会被填入该数组中



## shell_exec函数介绍
`shell_exec` 函数==用于通过 shell 环境执行系统命令，并将完整的输出结果作为字符串返回==，无法在web页面直接回显结果内容。它与 PHP 的反引号 (`` ` ``) 执行运算符功能完全相同。

- 语法：
```
shell_exec ( <$系统命令> )
```
### shell_exec函数别名( \` )：
==使用反引号( \` )简写，可以代替shell_exec ( )命令==
```
例：`<$系统命令>`; 等同于调用 shell_exec('<$系统命令>')
```





## passthru函数介绍
`passthru()` 函数==用来执行外部系统命令，并把命令执行后的原始输出直接回显并传送到浏览器或标准输出==。它适合输出二进制数据（如图片或流媒体），且不需要使用 `echo` 等输出语句。

- 语法：
```
passthru(<$系统命令>, <结果码>)
					(可选参数)
```




## popen函数介绍
`popen` 函数==用于打开一个指向进程的管道，通过执行指定的系统命令来启动一个新进程==，不会直接在web页面返回结果。

- 语法：
```
popen(<$系统命令>, <mode>)
```
**mode**：连接模式。`'r'` 表示读取进程输出，`'w'` 表示向进程写入数据

主要特点

- **单向管道**：==返回的文件指针只能用于读（`fgets`、`fread`）或写（`fwrite`）==，不能同时双向操作。
- **必须关闭**：操作完成后，==必须使用 `pclose()` 函数来关闭这个文件指针==，以释放系统资源。
- **返回值**：==成功时返回文件指针（类似于 `fopen`），出错时返回 `false`==

## proc_open函数介绍
`proc_open` 是==一个功能强大的执行外部程序的函数==。与 `exec` 或 `system` 相比，它能让你双向读写进程的输入输出，并对子进程进行精细控制；无法在web页面直接回显结果内容。

- 语法：
```
resource proc_open ( 
    <$系统命令>, 
    array <$descriptorspec>, 
    array <&$pipes>, 
    string <$cwd>, 
    array <$env>, 
    array <$other_options> 
           (可选参数)
)
```

核心参数说明
- **`descriptorspec`**：描述符规范数组。告诉 PHP 如何将输入/输出（如标准输入 `0`、标准输出 `1`、标准错误 `2`）映射到子进程。
- **`pipes`**：会被设为索引数组，存放对应子进程输入/输出端的文件指针（Stream 资源）。
- **`cwd`**：命令执行的初始工作目录。
- **`env`**：要传递给执行进程的环境变量数组。
- **`other_options`**：附加选项（如 Windows 下的 `bypass_shell` 等

# 常见代码注入函数/方法介绍


## eval()函数介绍
`eval()` 是一个语言构造器，==用于将字符串作为合法的 PHP 代码来执行==。它能动态运行代码并继承当前环境的变量范围，但因巨大的安全风险，通常极力推荐禁止或谨慎使用

- 语法：
```
eval(<字符串代码>)
```

## assert函数介绍==(7.2.0版本时该函数被弃用，8.0.0版本后被删除)==
是一个==用于检查断言（Expectation）是否为真的调试工具==。如果表达式结果为假（false），它会触发错误或抛出异常，常用于开发阶段的完整性检查

- 语法：
```
assert(<代码语句>)
```

主要特性
- **零成本生产环境**：在生产环境中可以将其关闭，编译时会被优化掉，不影响运行速度。
- **行为控制**：通过 `php.ini` 中的 `zend.assertions` 参数控制开启（值为 1）或关闭（值为 -1）。
- **错误处理**：断言失败时，可配置抛出 `AssertionError` 异常或发出警告

## call_user_funs_array函数介绍
`call_user_func_array` 是==一个强大的回调函数调用工具==。它接受两个参数：第一个是要调用的回调函数，第二个是一个包含参数的数组，并把数组中的元素作为变量传递给目标函数

- 语法：
```
call_user_func_array('<my_function_name>', <array(<$arg1>, <$arg2>)>);
```

1. `callback`：要调用的目标函数或类方法。
2. `args`：打包成数组的参数列表。如果键名是数字，按顺序传递；如果是字符串键名（PHP 8+），则作为命名参数传递

核心特点
- **动态调用**：可以在运行时通过字符串或数组决定调用哪一个函数或方法。
- **数组传参**：把多个参数放入一个数组中统一传递，非常适合参数数量不固定或来自动态变量的场景。
- **支持类方法**：除了普通函数，还能调用类静态方法和对象的方法

## create_function函数介绍
`create_function` 是 PHP 中==用于根据传递的代码字符串动态创建匿名函数的内置函数==。由于其底层实现类似于 `eval()`，存在严重的安全隐患和性能问题，==该函数已在 **PHP 7.2.0** 中被废弃，并在 **PHP 8.0.0** 中被完全移除==

- 语法：
```
create_function('<$args>', '<$code>')
```
1. `$args`：声明的参数列表（字符串形式，多个参数用逗号隔开）。
2. `$code`：函数执行的代码内容（字符串形式）



## array_map函数介绍
`array_map` 函数==用于将一个回调函数作用到给定数组的每个元素上，并返回处理后的新数组==

- 语法：
```
array array_map ( <$callback> , <$array1> , <$*> )
										  (可选参数)
```

1. `$callback`：要调用的处理函数。如果设为 `null`，则合并所有数组为多元数组。
2. `$array1`：要遍历的第一个数组。
3. `$*`：可选项，支持传入更多数组
