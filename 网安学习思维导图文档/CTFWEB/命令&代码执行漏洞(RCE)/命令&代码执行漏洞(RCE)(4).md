### 补：usort函数介绍
`usort` 函数==用来用你自己的规则排序数组==。它会改变原数组，并且会删除原有的键名，换成新的数字键名；当PHP版本小于5.6版本之前

- 语法：
```
usort(<array>, <callback>);
```

- **array**：必填。你要排序的数组。
- **callback**：必填。你写的比较函数。这个函数需要接收两个参数（代表数组里邻近的两个值），并返回一个数字：
    - 如果第一个值小于第二个值，返回小于 0 的数（比如 `-1`）。
    - 如果两个值相等，返回 `0`。
    - 如果第一个值大于第二个值，返回大于 0 的数（比如 `1`）


## 利用PHP大于7版本==（7.0 ~ 7.4）==中的assumed机制进行绕过
**利用 PHP 7.x 的 "Assumed" 机制配合统一变量语法（Uniform Variable Syntax）** 是一种极为经典的绕过技巧。该技术常用于完全不需要单双引号（`'`、`"`）甚至不需要美元符号（`$`）的环境下执行任意代码

1. ==在php7+版本中（7.0 ~ 7.4）==，如果引用一个未被定义的变量，代码中出现一个未用引号包裹、且未定义的裸标识符
	- PHP 会首先尝试将其作为常量（Constant）进行查找。
	- 查找失败后，PHP 会触发 `E_WARNING` 或 `E_NOTICE`（_Use of undefined constant xxx - assumed 'xxx'_），并**自动将其强制回退当作同名字符串 `'xxx'`** 处理，该变量会被当做字符串处理


2. PHP 7 的表达式直接调用语法
==在 PHP 7.0 及以上版本中，官方引入了统一变量语法，允许任意返回可调用值的表达式后直接跟 `()` 进行函数调用，即支持 `(expression)()` 语法==

例：

- **组合效果**： `(system)(whoami);` 
- → 被 PHP 自动解析为 `('system')('whoami')` 
- → 直接触发 `system('whoami')` 命令执行。

## 利用php7+版本的自动字符转义机制进行绕过
==在 PHP 7.0+ 版本中，引入了**Unicode 码点转义机制（`\u{xxxx}`）**，并结合了**统一变量语法（Uniform Variable Syntax）**。安全测试人员与攻击者经常利用该特性，在双引号字符串或 Heredoc 内部使用转义序列（Unicode、十六进制、八进制）构造任意关键字，从而彻底绕过基于正则或黑名单的 WAF 过滤==

### 核心转义机制原理

PHP 解析器在双引号 `"..."`、反引号 `` `...` `` 以及 Heredoc 语法结构中，会自动将特定的转义字符解析为对应的 ASCII 字符

- ==在php7+版本中，八进制、十六进制和Unicode编码的字符都会被自动转义==
- 其中八进制以反斜杠`\`开头，十六进制以反斜杠加`x`即`\x`开头，Unicode以`\u`开头

**Unicode 码点转义（PHP 7.0+ 新增）**： 语法为 `\u{...}`，花括号内为 16 进制码点。
例：
- `"\u{73}\u{79}\u{73}\u{74}\u{65}\u{6d}"` 会被 PHP 自动转换为字符串 `"system"`。
- 支持前导零填充（如 `\u{0073}`），便于混淆特征码

## 多重传参绕过

**多重传参（参数解耦 / 跨通道传参）是一种通过**将“执行指令”与“恶意载荷”拆分到不同参数或 HTTP 通道**来规避 WAF 与正则检测的经典技巧。
其本质在于：让被 WAF 重点检查的参数保持无害形式，而将真实的敏感函数名与命令载荷隐藏在未被深度检查或被忽略的辅助参数中**


- ==动态可变函数与参数解耦==
当 WAF 严格监控入口参数中的敏感关键字（如 `system`、`exec`、`passthru`、`phpinfo`）时，入口参数仅负责建立动态调用结构，不包含任何敏感词

**绕过逻辑**：
- ==WAF 检查 `$_GET['code']` 时，只看到 `$_GET[a]($_GET[b]);`，不包含任何黑名单字符。==
- ==PHP 解析时，动态从 `$_GET['a']` 提取 `system`，从 `$_GET['b']` 提取 `id`，完成 `system('id')` 执行==

## 取反符号绕过

**取反符号（按位非操作符 `~`）绕过**是一种通过将不可见字符进行按位取反运算，从而在完全不出现任何字母和数字（无字母数字 RCE）的情况下构造任意系统函数与命令的经典技巧

在 PHP 中，按位取反运算符 `~` 可以直接作用于字符串。当对一个单字节字符进行按位取反时，PHP 会对其二进制的每一个 bit 进行翻转

由于标准可见 ASCII 字母（`a-z`, `A-Z`, `0-9`，范围在 `0x30` ~ `0x7A`）取反后得到的字节数值均落在 `0x80` ~ `0xFF`（不可见字符 / 扩展 ASCII 范围），这些字符的 URL 编码形式（如 `%8C%86...`）**不包含任何英文字母和数字**

### getallheaders()函数介绍
`getallheaders()` 函数==用来获取当前请求的所有 HTTP 请求头信息==。它返回一个包含所有请求头的关联数组。在 Apache 服务器中，它是 `apache_request_headers()` 的别名；以数组形式返回请求头信息结果

- 语法：
```
getallheaders()
```

使用注意事项与环境兼容

- **环境限制**：该函数主要支持 Apache 服务器环境（作为 Apache 模块运行）。如果在 Nginx、IIS 或使用 FastCGI 等非 Apache 环境下，原生 `getallheaders()` 可能不存在。
- **兼容替代方案**：在非 Apache 环境中，可以通过遍历 `$_SERVER` 超全局变量来手动封装兼容函数，提取以 `HTTP_` 开头的键值并转换格式



### get_defined_functions ()函数介绍
`get_defined_functions()` 函数==用来获取所有已定义的函数列表==。它会返回一个多维数组，里面包含系统自带的内部（内置）函数以及你自己编写的用户自定义函数；并返回相应的函数结果

- 语法：
```
get_defined_functions ( <$exclude_disabled> )
```
**$exclude_disabled**：可选参数。如果设置为 `true`（默认值），则会从返回结果中排除被禁用的函数（通过 `disable_functions` 配置项禁用的函数）

返回值结构
该函数返回一个包含两个键名的大数组：

- `$arr['internal']`：保存所有系统内置函数和扩展提供的函数（如 `strlen`、`array_map` 等）。
- `$arr['user']`：保存所有用户在代码中通过 `function` 关键字自定义的函数

## 补：php中的字符自增机制

==PHP 长期沿用 Perl 的习惯，支持对纯字母及字母数字组合的 ASCII 字符串进行递增（`++`）运算。当字符达到 `'Z'` 时会自动向左进位变为 `'AA'`。但自 PHP 8.3 起，该运算符处理非数字字符串的行为已被软弃用，官方推荐改用专用的 `str_increment()` 函数==

核心功能特点

- **字符进位机制**：对字母递增时，`'Z'` 或 `'z'` 会进位到下一位。例如 `'W'` 递增后逐个变更为 `'X'`、`'Y'`、`'Z'`、`'AA'`。
- **字母数字组合**：支持诸如 `'A8'`、`'A08'` 的混合递增。
- **潜在风险**：若字符串外观类似科学计数法（如 `"5d9"` 隐式转为浮点数），直接使用 `++` 会导致非预期的数值计算错误

### str_increment()函数介绍
==为避免隐式类型转换及软弃用提示，PHP 8.3 引入了专门的 [str_increment](https://www.php.net/manual/en/function.str-increment.php) 函数==

- 语法：
```
str_increment(<ASCII字符串>)
```

==(注：**字符限制**：输入必须为非空字母数字 ASCII 字符串，否则会抛出异常)==

## 使用php的字符自增机制和弱类型字符串结合Bypass
==在 PHP 代码执行（RCE）与安全测试中，**字符自增（`++`）机制**配合 **PHP 弱类型隐式转换（Type Juggling）** 构成了一种极为纯粹的“无字母数字（No Alphanumeric）”代码执行构造手法==

==该技巧仅依赖 `[]`、`_`、`+`、`.`、`=` 等几个纯符号，利用 PHP 的隐式类型转换获取初始字符，再通过 Perl 风格的字符串自增生成任意 ASCII 字符，最终动态拼装出任意函数名并触发执行==

### 核心机制原理
- 机制一：弱类型的字符串隐式转换（Type Juggling）
	在 PHP 中，当数组、特殊浮点数或布尔值与字符串进行拼接（连接符 `.`）或在字符串上下文中使用时，PHP 会自动触发类型转换
	例：
	- `[] . ""` $\implies$ 字符串 `"Array"`（直接提取首字母 `'A'`、小写字母 `'a'`、`'r'`、`'y'`）
	- `(1/0) . ""` $\implies$ 字符串 `"INF"`（提取 `'I'`, `'N'`, `'F'`）
	- `(0/0) . ""` $\implies$ 字符串 `"NAN"`（提取 `'N'`, `'A'`）
- 机制二：Perl 风格的字符串自增（String Increment）
- 机制三：字符串的数组下标取值（String Offset）
