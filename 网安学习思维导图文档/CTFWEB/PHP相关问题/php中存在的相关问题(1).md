## php中的一些比较有意思的函数

### intval函数
`intval()` 是 PHP 的内置函数，==用于将变量转换为10进制整数（Integer）类型==。它常用于数据过滤、防止 SQL 注入或确保参与数学运算的数据格式正确

- 语法
	`int intval ( <$var> , int <$base> = <10>  )`
							（可选参数）
	
- **`var`**：需要转换的变量（支持字符串、浮点数、布尔值等，**但不能是数组或对象**(**当传入为非空数组时，intval()函数的返回值为1**)）。
- **`base`**（可选）： 进制基数 ，默认为 `10`（十进制）。当 `var` 为字符串时，此参数生效

### preg_match函数

`preg_match` 是 PHP 中==用于执行**正则表达式匹配**的核心函数==，成功返回 1，未匹配返回 0，出错返回 `false`

- 语法
	`int preg_match ( 
	string <$预定字符串> , 
	string <$输入的字符串> , 
	array <$存储结果数组> , 
	int $flags = 0 , 
	int $offset = 0 
	)`

- `$预定字符串`：正则表达式模式（必须以定界符包围，如 `/pattern/`）。
- `$输入的字符串`：要搜索的输入字符串
- **`$matches`**（可选参数）：用于存储匹配结果的数组，`$matches[0]` 将包含完整匹配的文本，`$matches[1]` 及后续元素包含子组匹配的内容，以此类推

### call_user_funs函数

`call_user_func` 是 PHP 中的一个内置函数，==用于通过回调函数（动态地）调用指定的函数或方法，并支持向其传递参数==

- 语法
	`call_user_func ( callable <$调用函数名> , mixed ...<$args> )`
											（可选参数）
											

...<$args>：可选。传递给回调函数的参数，可以有多个


### get_defined_vars函数

PHP 中的 `get_defined_vars()` 函数==用于获取**当前作用域内所有已定义变量**的列表，并以多维数组的形式返回==

- 语法
	`array get_defined_vars ( void )`

(注：==**作用域**：如果在函数内部调用，返回的是函数内部的局部变量；如果在全局作用域调用，返回的是全局变量==)

### gettext()函数

`gettext()` 是 PHP 中==用于实现**国际化 (i18n)** 和**多语言本地化**的核心函数==

- 语法
	`gettext(<$变量名>)`


要使用 `gettext()`，通常需要配合以下几个核心函数来定位和加载语言包：
1. **`setlocale()`**：设置当前的区域和语言环境（如 `zh_CN` 或 `fr_FR`）
2. **`bindtextdomain()`**：指定语言包 `.mo` 文件所在的绝对路径
3. **`textdomain()`**：指定要加载的语言包域名（即 `.mo` 文件的名称）

#### __ 函数

gettext()函数的简化写法，与gettext()函数作用等效，简化为

`_(<$变量名>)`
