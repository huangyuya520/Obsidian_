
# one.xxx.edu.cn 存在数据中台SQL越权通道致门户系统管理员凭据泄露与口令离线恢复漏洞


## 漏洞描述

门户“数据中台”视图预览接口 previewData 允许调用方传入任意 SELECT 语句并在门户数据库（bladex）上以 root 身份执行、回显结果集；白名单仅约束主表，通过投影位置的标量子查询即可读取同库任意表。该通道已被用于读取全校师生个人信息；进一步证实其可直达“管理员凭据”层：

1. 读取 information_schema 元数据，取得 blade_user 全部列（含 password 口令哈希列与 plaintext 明文口令列，数据库连接身份 root@10.30.70.117，MySQL 5.7.41-log）；

2. 按 identity='SYSTEM' 定向取得全部 3 个系统账户：门户系统管理员 sceduAdmin（blade_role 9999 管理员角色组）、edu（角色 2001,10001）、GH_000001（文件传输助手）；其中 sceduAdmin 与 GH_000001 共享同一口令哈希（同批初始口令特征）；

3. 口令哈希算法为 SpringBlade 框架默认 encrypt = sha1(md5Hex(password))（blade-tool 开源实现，无盐、单轮）；离线复算即完成 edu 账户明文口令恢复：Aa123456；

4. sceduAdmin 口令经 rockyou 全量 6,290,018 条与 250 余条定向变体均未命中，为非字典强口令；

5. 门户公网密码登录通道（blade-auth）被网关强制令牌校验阻止（9 条路径变体全部 401），泛微 OA 出厂默认口令（sysadmin/1）已修改，财务门户存在账户锁定机制——上述控制有效，本轮登录尝试未产生任何成功会话，已如实记录；
