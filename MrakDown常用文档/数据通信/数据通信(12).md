
# VLAN


## VLAN的划分方式
**VLAN 的划分方式**，本质上是交换机在入向接口（Ingress）接收到不带标签（Untagged）的以太网帧时，依据何种物理或逻辑特征为其分配内部 **VID（VLAN ID）** 的分类规则。

在数据通信标准体系中，VLAN 划分分为**静态划分**（基于端口绑定，终端移动需人工改配）与**动态/逻辑划分**（基于帧内特征或准入认证自动归类，终端移动时 VLAN 归属自动跟随）两大类，具体包含以下五种标准方式及一种企业网准入联动扩展方式：


一、 五种标准 VLAN 划分方式

1. ==基于接口划分（Port-based VLAN）(常用)—— 静态划分==

- **工作机制**：将交换机的物理接口（或 Eth-Trunk 链路聚合组）静态绑定到指定的 **PVID（Port Default VLAN ID）**。所有从该接口进入的 Untagged 帧，无论上层携带何种数据，均直接归入该接口的 PVID。
    
- **工程特性**：配置最简单，交换芯片（ASIC）无需解析帧内高层字段即可直接查表转发，**转发性能最高**。缺点是缺乏灵活性——当终端更换物理接口或调整工位时，网络管理员必须同步修改交换机端口配置。
    
- **适用场景**：工位固定的办公区、服务器机房接入、网络汇聚与核心层互联（现网 80% 以上的二层接入采用此方式）。























2. ==基于 MAC 地址划分（MAC-based VLAN）(常用)—— 动态划分==

- **工作机制**：在交换机上预先建立“终端源 MAC 地址与 VID”的静态映射表。当接口收到 Untagged 帧时，提取二层帧头的**源 MAC 地址**进行检索；命中映射表则打上对应 VID，未命中则回退采用接口的 PVID。
    
- **工程特性**：终端在交换机不同端口间移动或通过无线 AP 漫游时，所属 VLAN 自动跟随，无需重新配置接入端口。缺点是大规模园区网中预先收集、维护全网终端 MAC 映射表的工作量极大，且存在 MAC 地址仿冒的安全隐患。
    
- **适用场景**：小型移动办公区、无线接入点（AP）终端归类、固定资产编号明确的特定业务终端。

- 划分原则：
	- 交换机内部建立并维护了一个MAC地址与VLAN ID的对应表。当交换机接收到计算机发送的Untagged帧时，交换机将分析帧中的源MAC地址，然后查询MAC地址与VLAN ID的对应表，并根据对应关系把这个帧划分到相应的VLAN中。
- 特点：
	- 这种划分实现稍微复杂，但灵活性得到了提高。
	- 当计算机接入交换机的端口发生了变化时，该计算机发送的帧的VLAN归属不会发生变化（因为计算机的MAC地址没有变）。
	- 但这种类型的VLAN划分安全性不是很高，因为恶意计算机很容易伪造MAC地址。






3. 基于 IP 子网划分（IP Subnet-based VLAN）—— 动态划分

- **工作机制**：交换机向后解析 Untagged 帧的网络层（第 3 层）IPv4 头部，提取**源 IP 地址**，并根据预设的“IP 网段/子网掩码与 VID 映射表”分配对应的 VLAN。
    
- **工程特性**：便于按业务网段统一规划权限；当下游通过普通无网管交换机（“傻瓜交换机”）串联了多个不同网段的主机时，上联交换机只需单个物理端口即可将不同子网的流量自动拆分为多个独立 VLAN。缺点是交换机需要跨层解析三层头部，对纯二层交换芯片有一定处理开销，且无法识别非 IP 协议报文。



4. 基于协议划分（Protocol-based VLAN）—— 动态划分

- **工作机制**：依据以太网帧头部中的**协议类型（Type/Length）字段**及封装格式（Ethernet II、802.3 SNAP、802.3 LLC 等）匹配对应 VLAN，例如将 IPv4（`0x0800`）、IPv6（`0x86DD`）或传统 IPX 流量分配至各自独立的广播域。
    
- **工程特性**：能够将特定网络层协议的广播报文限制在专属逻辑拓扑内，避免异构协议广播相互干扰。由于现代数据通信网络已全面收敛至 IP 协议栈，该方式在现网中极少单独部署，仅见于老旧系统迁移或特殊工业控制总线隔离场景。



5. 基于策略划分（Policy-based VLAN）—— 组合维度动态划分

- **工作机制**：将多种维度进行逻辑“与”组合绑定，典型组合为 **`入接口 + 源 MAC 地址 + 源 IP 地址`** 三元组映射单一 VID。只有同时满足全部预设特征的 Untagged 帧才会被赋予目标 VLAN 标签。
    
- **工程特性**：隔离粒度最精细、防私接与防地址仿冒能力最强；缺点是策略条目配置复杂度高，维护成本大，适用于财务核心系统、涉密研发终端等高安全合规要求的接入场景。

- 计算机发出的数据帧不带任何标签。对已支持VLAN特性的交换机来说，当计算机发出的Untagged帧一旦进入交换机后，交换机必须通过某种划分原则把这个帧划分到某个特定的VLAN中去。
 - VLAN的划分包括如下5种方法：
	- 基于接口划分：根据交换机的接口来划分VLAN。

- 网络管理员预先给交换机的每个接口配置不同的PVID，当一个数据帧进入交换机时，如果没有带VLAN标签，该数据帧就会被打上接口指定PVID的标签，然后数据帧将在指定VLAN中传输。
	- 基于MAC地址划分：根据数据帧的源MAC地址来划分VLAN。

- 网络管理员预先配置MAC地址和VLAN ID映射关系表，当交换机收到的是Untagged帧时，就依据该表给数据帧添加指定VLAN的标签，然后数据帧将在指定VLAN中传输。
	- 基于IP子网划分：根据数据帧中的源IP地址和子网掩码来划分VLAN。

- 网络管理员预先配置IP地址和VLAN ID映射关系表，当交换机收到的是Untagged帧，就依据该表给数据帧添加指定VLAN的标签，然后数据帧将在指定VLAN中传输。
	- 基于协议划分：根据数据帧所属的协议（族）类型及封装格式来划分VLAN。

- 网络管理员预先配置以太网帧中的协议域和VLAN ID的映射关系表，如果收到的是Untagged帧，就依据该表给数据帧添加指定VLAN的标签，然后数据帧将在指定VLAN中传输。
	- 基于策略划分：根据配置的策略划分VLAN，能实现多种组合的划分方式，包括接口、MAC地址、IP地址等。

- 网络管理员预先配置策略，如果收到的是Untagged帧，且匹配配置的策略时，给数据帧添加指定VLAN的标签，然后数据帧将在指定VLAN中传输。
