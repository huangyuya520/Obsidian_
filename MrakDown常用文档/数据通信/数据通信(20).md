
# 网络管理

## 概念
在数据通信（Datacom）领域，**网络管理（Network Management）**是指通过特定的协议、工具和架构，对网络中的各类基础设施（路由器、交换机、防火墙、无线控制器及传输链路等）进行持续的**监控、配置、故障排查、性能优化与安全管控**，从而保障网络的高可用性（High Availability）与业务连续性。


==一、网络管理的核心功能模型（FCAPS）==

国际标准化组织（ISO）在 OSI 网络管理框架中定义了经典的 **FCAPS 模型**，这是所有网管系统设计的理论基石：

- **故障管理（Fault Management）：** 实时检测、隔离并修复网络异常。包括链路中断（Link Down）、设备宕机、路由震荡的告警收敛，以及通过日志和告警报文定位故障根因。
    
- **配置管理（Configuration Management）：** 负责设备全生命周期的配置下发、系统版本升级、配置文件的定时备份与快速回滚，以及配置合规性审计（防止未经授权的命令行变更）。
    
- **计费管理（Accounting Management）：** 统计网络资源的使用情况（如端口流量、会话时长、用户带宽占用），不仅用于运营商计费，在企业网中也用于部门成本分摊与链路容量规划。
    
- **性能管理（Performance Management）：** 持续采集并分析网络运行指标（KPI），包括接口吞吐量、丢包率、时延（Latency）、抖动（Jitter）以及设备 CPU 和内存利用率，用于提前发现性能瓶颈。
    
- **安全管理（Security Management）：** 控制对网络资源及网管系统本身的访问权限。涵盖 AAA 认证（RADIUS/TACACS+）、ACL 策略审计、加密通信通道维护及异常流量检测。

- 网络管理（Network Management）分为两类：
	- 第一类是对网络应用程序、用户账号（例如文件的使用）和存取权限（许可）的管理。它们都是与软件有关的网络管理问题，这里不作深入解释。
- 第二类是对构成网络的硬件即网元的管理，包括防火墙、交换机、路由器等等。本课程主要针对此类网络管理。
- 一般企业网络中会有专门的部门或者人员负责网络的管理与运维。
- 注：
	- NE（Network Element，网元）：即网络单元，包含硬件设备及运行其上的软件。通常一个网络单元至少具有一块主控板，负责整个网络单元的管理和监控。主机软件运行在主控板上。
	- 通常网络运维的操作都属于网络管理的范畴，本章后续所指的网络管理指对网络进行管理和维护。
