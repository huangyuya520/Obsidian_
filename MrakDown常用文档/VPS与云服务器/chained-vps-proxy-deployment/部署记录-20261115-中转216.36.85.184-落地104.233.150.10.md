# 二级代理重建记录（中转 216.36.85.184 → 落地 104.233.150.10）

- 日期：2026-11-15（Asia/Shanghai）
- 目标：把中转机 `216.36.85.184`（美国 CN2GIA，LXD NAT VPS）作为客户端入口，落地机 `104.233.150.10`（美国 圣何塞 PEG TECH/AS54600）作为最终出口，重建一条稳定、低延迟、可自愈的链式代理，消除旧链路的“时好时坏 / 超时 / 断链”。

## 1. 最终拓扑

```text
客户端(V2rayN/xray/sing-box)
   │  ① VLESS-Reality-Vision (TCP)  主 216.36.85.184:24065 / 备 24051

   │  出站 chain-landing：VLESS-Reality-Vision → 104.233.150.10:44300
   ▼
落地机 104.233.150.10  sing-box 1.14.4
   │  入站 vless-reality 0.0.0.0:44300（uuid + xtls-rprx-vision）
   │  出站 direct
   ▼
Internet —— 最终出口 IP = 104.233.150.10（San Jose, US, AS54600 PEG TECH，hosting=false）
```

**为什么这样设计（对比旧方案）**
- 旧方案依赖 `land-tunnel.service` SSH 隧道（中转 ssh 到旧落地 23.134.76.135:53930），旧落地早已失效 → 隧道 `Connection refused` 无限重启，这是“时好时坏”的主因之一。
- 新落地自带公网映射端口 **44300**（TCP+UDP），中转可直接以 VLESS-Reality 出站连过去，**彻底去掉 SSH 隧道这一单点**，也无需在落地面板追加端口。
- 中转→落地都在美国境内，延迟低；Reality 握手伪装为正常 TLS（target=www.microsoft.com），抗主动探测。
- 落地 sing-box、中转 x-ui、UDP 节点、watchdog 全部 `Restart=always`，断线自动恢复。
- 备选 Hysteria2/TUIC 走 QUIC + 用户态 BBR，绕开 NAT 容器内核无法启用 BBR 的限制（本机实测 Hy2 带宽 ~6.3–6.6 MB/s，高于 Reality 的 ~4.7–5.0 MB/s）。

## 6. 原“时好时坏”根因与本次修复

1. **旧落地失效**：出站/隧道指向旧落地 23.134.76.135，已不可达 → 改为直连新落地 104.233.150.10:44300。
2. **SSH 隧道单点**：land-tunnel 反复失败重启 → 直接废弃，改为 Reality 直连出站。
3. **双套服务冲突**：旧 hy2chain/udp 节点全部指向旧隧道口 24099 → 统一改为新落地 44300，仅保留一套 udp-nodes。
4. **无自愈**：新增 chain-watch watchdog + 各服务 Restart=always。
5. **容器无法开 BBR**：用 Hysteria2/TUIC（QUIC+用户态拥塞控制）作为高速备份，绕开内核限制。
